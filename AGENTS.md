# Regras do Projeto

- **Mensagens de Commit**: Todas as mensagens de commit (`git commit -m "..."`) geradas ou sugeridas devem ser **obrigatoriamente em português do Brasil** (pt-BR). Quando utilizar Conventional Commits (ex: `feat:`, `fix:`, `refactor:`, `style:`, `docs:`, `ci:`), a descrição e o corpo da mensagem devem estar sempre em português do Brasil (exemplo: `feat: adicionar suporte a novo tema` ou `fix: corrigir conflito de classes flex`).
- **Tailwind CSS v4**: Este projeto utiliza a versão 4 do Tailwind CSS. Nunca utilize a sintaxe legada de gradientes `bg-gradient-to-*`. Sempre utilize `bg-linear-to-*` (`bg-linear-to-r`, `bg-linear-to-b`, etc.).
